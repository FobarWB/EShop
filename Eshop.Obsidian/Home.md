# EShop Knowledge Base

Notes about the EShop services, architecture decisions and what was learned along the way.
Developers and AI agents read and maintain the same notes. Read the [knowledge workflow](Workflow.md) before changing them.

- [Services](Services/Services.md): one note per service — purpose, endpoints, data, dependencies.
- [Decisions](Decisions/Decisions.md): architecture decision records (why, not only what).
- [Learning](Learning/Learning.md): notes on PostgreSQL, Docker, RabbitMQ and other technologies studied in this project.

Open the `Eshop.Obsidian` folder as an Obsidian vault. Links to source code use relative paths such as
`../../src/EShop.ShoppingCart/`; Obsidian does not open files outside the vault, but editors and agents follow them.
