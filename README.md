# EShop

Learning pet project: an online shop built from ASP.NET Core Web API services (.NET 10) and an Angular client,
on top of the Northwind sample database.

- `src/`: API services, Angular client and the shared EF Core data layer.
- `archive/`: SQL Server-era code, kept for reference.
- `Eshop.Obsidian/`: knowledge vault (services, decisions, learning notes).

Build and run commands: [AGENTS.md](AGENTS.md#commands).
